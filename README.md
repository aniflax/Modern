# Modern

Static HTML templates — `modern/` (Modern) and `arkit/` (Arkit).

## Workflow — Auto Commit & Push

> **Every change in any folder must be committed and pushed to GitHub immediately.**

1. `git add -A`
2. `git commit -m "<concise description>"`
3. `git push origin main` → `git@github.com:aniflax/Modern.git` (`main` branch)

Applies to **all folders** (root, `modern/`, `arkit/`, any new directory). Do not leave uncommitted or unpushed changes. See `AGENTS.md` for the full rule.

## Structure

- `modern/` — Modern template (homepage variants `index.html`, `index-2.html`, etc.)
- `arkit/` — Arkit template
- `AGENTS.md` — agent workflow and commit rules
